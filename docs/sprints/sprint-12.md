## Goal

Deliver the smallest current-only Industry classification and participation
slice for the exact supplied cohort already admitted by current Market Regime
V2. The source is one operator-acquired artifact from the exact official NSE
Indices URL:

```text
https://www.niftyindices.com/IndexConstituent/ind_nifty100list.csv
```

The tool must preserve the literal source tier `INDUSTRY`; it must never relabel
that field as the official NSE Indices `Sector` tier. An observed result requires
an exact retained classification for every supplied member and emits only
aggregate Industry member/advance/decline/unchanged counts, attribution,
timestamps, and opaque identities.

## Implemented public and private boundaries

The delivered implementation's authoritative classification module is:

```text
swing_trading_ai_assistant.market_data.current_industry_classification
```

It owns the strict owner input, exact artifact parser, supplied-cohort
projection, private snapshot, typed classification failures, immutable archive
port/implementation, canonical identities, and classification runtime identity.

The delivered implementation's authoritative aggregate module is:

```text
swing_trading_ai_assistant.sector_analysis.current_industry_participation
```

Its public reducer accepts the existing four Market Regime V2 evidence inputs
plus the retained classification outcome. It internally invokes the paired
Market Regime V2 evaluator and immediately consumes the private handoff. It does
not accept a Market Regime V2 report or handoff from the caller.

Observed output is
`current-supplied-cohort-industry-participation@v1`. Its rows are
`IndustryCountV1` values sorted by the exact Industry label. Non-observed output
uses exactly `MALFORMED_EVIDENCE`, `UNSUPPORTED_CAPABILITY`, or
`INSUFFICIENT_EVIDENCE`, closed declaration-ordered reasons, and
`industries = null`.

No CLI, API, MCP, network acquisition, provider adapter, source registry, or
public member transport is part of the first implementation.
